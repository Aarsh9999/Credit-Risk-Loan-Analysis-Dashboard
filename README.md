# Credit Risk & Loan Delinquency Analysis

📌 Project Overview

This is my first Data Analytics project, created using Microsoft Excel to analyze customer and loan data and understand patterns related to loan delinquency.

The project focuses on exploring the dataset through data cleaning, pivot tables, calculations, and an interactive dashboard.

🎯 Objective

The main objective of this project was to analyze different customer and loan-related factors and identify patterns in delinquent accounts.

The analysis covers:

Loan balances
Credit scores
Credit utilization
Missed payments
Employment status
Credit card types
Customer locations
Delinquent accounts
📊 Dataset

The dataset contains information on 1,000 customers.

Each customer record includes several financial and demographic attributes, along with information about delinquent accounts.

🔎 Key Observations

The dashboard highlights the following observations from the dataset:

Overall delinquency stood at 16%, meaning 160 out of 1,000 accounts were delinquent.
Los Angeles had the highest number of delinquent accounts, with 42 accounts.
Chicago had the highest average loan balance, at approximately $50.3K per customer.
Customers in the 25–50% credit utilization category accounted for the highest number of delinquent accounts, with 74 accounts.
Employed customers represented the highest number of delinquent accounts, with 78 accounts.

These observations are based on the dataset and dashboard analysis. They describe patterns within the data and should not be interpreted as causal relationships.
